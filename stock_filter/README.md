# A股筛选系统

A股市场每日筛选工具，基于同花顺人气榜和东方财富涨停数据，执行三个筛选条件并推送结果。

## 功能

1. **连板筛选**：今日涨停 + 连板 + 10日内接近期高点 + 非ST + 主板，按人气排名前20
2. **回调筛选**：今日涨8%以内 + 人气前150 + 成交额放大 + 20日内有涨停 + 20日内接近期高点 + 非ST + 主板，按人气排名前20
3. **断板筛选**：昨日涨停 + 今日未涨停 + 20日内接近期高点 + 非ST + 主板，按人气排名前20

## 输出

- 3张筛选结果图片保存到 `E:\StockFilter`
- 企业微信推送文字消息 + 图片

## 文件说明

- `stock_filter_v2.py` - 数据筛选与图片生成
